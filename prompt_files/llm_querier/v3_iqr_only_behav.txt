You will receive:
- A scene-level description
- A list of objects with IDs and natural-language descriptions

For EACH object, estimate how long it is likely to remain in the same location, and how uncertain you are.
Return a JSON array where each element includes:
- "id": the object id (integer or string)
- "p25_persistence_hours": positive float — 25th percentile time (in hours) the object stays stationary.
- "p75_persistence_hours": positive float — 75th percentile time (in hours) the object stays stationary. Ensure this is greater than the 25th percentile persistence hours by a reasonable percentage of the p25_persistence_hours.
- "persistence_uncertainty": one of ["low", "medium", "high"]
- "persistence_conf": float in [0.0, 1.0] — confidence in the answer, reflecting how predictable the behavior is (either in the object or in the familiarity of the object in this context). Should never be exactly 1 or 0 to avoid overconfidence.
- "static_likelihood": float in [0.0, 1.0] — probability that the object is effectively static
- "notes": short sentence explaining reasoning (max 1 sentence)

Guidelines:
- Consider the typical timescale/units for the object's likely persistence and then convert to hours.
- Objects that have some fixed components but can still move should not be treated as fully immovable; for example, the persistence estimate for a door concerns how long until it moves on its hinge.
- Structural or immovable objects such as walls or countertops should have very large persistence values (10000 to 200000 hours).
- Consider whether something is truly fixed (ex. wall, light pole), or if it can be moved, but is not frequently moved (poster, potted plant, large furniture). Objects that can be moved can have very long persistence times, but likely should not be as high as fully immovable entities.
- Actively moving objects such as vehicles, people, or objects being carried by people should have very short persistence (0.001 hours). Any movement of any part of person or other highly dynamic entity should be considered movement of the person.
- For objects that appear currently stationary but are capable of moving, estimate persistence based on typical patterns for the object, given the environment context. For example, minutes for a chair at an occupied desk, several hours for a chair at an office desk at night, minutes for utensils at an occupied kitchen counter, 3–24 hours for an unoccupied kitchen, 1 hour for a car at a grocery store, 4 hours for a car at an office building, etc.
- Consider processes/activities suggested by the context that would influence the movement of an object, for example:
---- Fork at an occupied table -- consider how often someone would reach for a fork.
---- Used fork at an empty table at a restaurant -- consider how quickly table would be cleared.
---- Objects around person eating at a table or working at a coffee shop -- consider meal duration or time spent working.
---- Car at a stoplight -- consider stoplight timing.
---- Car parked outside grocery store -- consider how long someone would spend in a grocery store.
---- Small table at a cafe -- consider how often it would be rearranged or moved for cleaning (vs large home dining room or conference room table that are heavier and have less traffic).
